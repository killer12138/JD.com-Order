# 订单管理系统 - 京东 & 美团

一个基于 React + Vite + NutUI 构建的双平台订单管理系统。

## 🎯 功能特性

### 📱 四个核心页面

1. **🛒 京东订单页面**
   - 京东风格的订单详情展示
   - 商品信息、价格、订单状态
   - 完整的订单操作按钮
   - 支持自定义商品图片

2. **⚙️ 京东配置页面**
   - 订单状态配置（标题、描述）
   - 商家信息配置
   - 商品信息配置（名称、规格、价格、备注）
   - **支持图片上传**（本地base64）
   - 收货信息配置
   - 实时预览更新

3. **🍔 美团订单页面**
   - 高保真美团外卖风格
   - 精美的UI设计和图标
   - 快捷操作按钮（更多、小问卷、致电骑手、再来一单）
   - 满意度评价入口
   - 更多推荐商家

4. **⚙️ 美团配置页面**
   - 订单状态配置
   - 商家信息配置
   - 商品信息配置
   - **支持图片上传**（本地base64）
   - 支付方式配置（微信、支付宝、银行卡）
   - 收货信息配置
   - **日期时间修改**（下单时间、支付时间、送达时间）
   - 实时预览更新

### ✨ 核心功能

- ✅ **图片上传功能**：支持 jpg、png、gif、webp 格式，最大 5MB
- ✅ **实时预览**：配置更新后自动切换到对应订单页面查看效果
- ✅ **数据独立**：京东和美团配置相互独立，互不影响
- ✅ **响应式设计**：完美适配移动端屏幕
- ✅ **美团高保真还原**：使用真实图标和设计，完美还原美团UI

## 📖 使用指南

### 1. 京东订单配置流程

1. 点击 **⚙️ 京东配置** 标签页
2. 配置订单信息：
   - 上传商品图片（可选）
   - 填写订单状态和描述
   - 配置商家名称和类型
   - 设置商品名称、规格、价格
   - 填写收货人和地址
3. 点击 **✅ 保存更新** 按钮
4. 自动切换到 **🛒 京东订单** 页面查看效果

### 2. 美团订单配置流程

1. 点击 **⚙️ 美团配置** 标签页
2. 配置订单信息：
   - 上传商品图片（可选）
   - 填写订单状态和描述
   - 配置商家名称和类型
   - 设置商品名称、规格、价格
   - 选择支付方式
   - 填写收货人和地址
   - 设置下单、支付、送达时间
3. 点击 **✅ 保存更新** 按钮
4. 自动切换到 **🍔 美团订单** 页面查看效果

### 3. 图片上传使用说明

**支持的图片格式**：
- JPG / JPEG
- PNG
- GIF
- WebP

**文件大小限制**：最大 5MB

**上传方式**：
1. 点击上传区域选择图片
2. 或点击"更换"按钮更换已上传的图片
3. 点击"删除"按钮移除图片

**注意事项**：
- 图片采用 base64 编码存储在浏览器内存中
- 刷新页面后图片会重置
- 建议使用压缩后的图片以获得更好的性能

## 🔥 核心特性说明

### 图片上传机制
采用 FileReader API 将图片转换为 base64 格式：
- ✅ 无需后端服务器
- ✅ 即时预览效果
- ✅ 支持图片更换和删除
- ✅ 文件类型和大小验证

### 数据隔离设计
京东和美团的配置数据完全独立：
- `orderData.jdItems` - 京东商品数据
- `orderData.items` - 美团商品数据
- `orderData.jdProductImage` - 京东商品图片
- `orderData.productImage` - 美团商品图片

### 响应式适配
- 📱 移动端优先设计
- 💻 最大宽度 750px
- 🎯 完美适配各种屏幕尺寸

## ⚠️ 注意事项

1. **数据持久化**：当前数据仅保存在内存中，刷新页面后会重置
2. **图片存储**：图片使用 base64 编码，建议上传压缩后的图片
3. **浏览器兼容**：建议使用现代浏览器（Chrome、Edge、Safari、Firefox）
4. **性能优化**：大量图片可能影响性能，建议控制图片大小
